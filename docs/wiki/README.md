# Wiki sources

These files are the pages of the
[GitHub wiki](https://github.com/egungor/stm32-desk-dashboard/wiki).
`.github/workflows/wiki-sync.yml` copies them to the wiki when they
change on `main` (this README is not copied).

- Edit the pages here, through a pull request. Changes made in the wiki's
  web editor are overwritten by the next sync.
- File name = page name (`Getting-Started.md` → "Getting Started").
  `_Sidebar.md` and `_Footer.md` are shown on every page.
- Links between pages are wiki links such as `(Getting-Started)`; they
  only work on the wiki, not when browsing this folder.
- The wiki summarises; the documents in the repository stay authoritative.
  When an interface, a status or a procedure changes, update both.
